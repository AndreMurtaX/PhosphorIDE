# The outline pane and F12, on outline.bas -- ten definitions, FIVE of them
# where a first-word scanner will not look: after a `:`, after `then`, after a
# numeric label, and TWO on one line after a named label. All ten compile and
# run; `phosphor run tools/lane/outline.bas` prints, in order,
# `function stringghost()` 1 5 3 4 5 6 7 true 42 3 -- eleven lines, the first
# from the string literal on line 4 and the last from the built-in call on 49.
key ^+o
wait 900
shot 130-ten-definitions

# A SINGLE CLICK MOVES THE CARET AND LEAVES THE KEYBOARD IN THE LIST. Row 6 is
# `22: sixth%()`, the second of the two definitions on line 22, so the column in
# the status bar is the proof that the jump used the NAME's column and not 1.
at 100 657
wait 700
shot 131-a-click-moves-the-caret

# And the arrow key still belongs to the list, which is how an outline is read.
key {DOWN}
wait 700
shot 132-arrowing-walks-the-file

# A double-click is "I have arrived": the caret AND the focus.
dblclick 100 582
wait 800
shot 133-a-double-click-hands-over-the-keyboard

# F12 on a call. Line 42 is `println second(2, 3)`; nine rights from the start
# of it puts the caret inside `second`, which is defined on line 11 after a `:`.
key ^g
wait 500
key ^a
type 42
key {ENTER}
wait 600
key {HOME}
key {RIGHT 9}
wait 300
key {F12}
wait 900
shot 134-f12-jumped-to-the-definition

# And the caret is now ON that definition's name, which is its own answer.
key {F12}

shot 135-f12-on-the-definition-itself

# A JUMP INTO ANOTHER FILE REBUILDS THE PANE, and this is the case that shows
# it: search for a word that lives in deep.bas, double-click the row, then reach
# the Outline tab BY CLICKING ITS HEADER rather than by pressing Ctrl+Shift+O --
# the action rebuilds, the tab header does not, so what is on screen is whatever
# GotoSource left behind. Without that rebuild the pane would still list
# outline.bas's ten functions while deep.bas is on screen, and clicking one
# would jump back into the file just left.
key ^+f
wait 700
key ^a
type bottom
key {ENTER}
wait 1600
dblclick 200 643
wait 1000
at 222 561
wait 700
shot 140-the-pane-follows-the-file

# AND A PARAMETER IS NOT A FUNCTION. deep.bas is `function down(n) local r`, so
# inside it the words `n` and `r` are variables -- and if a `function r()`
# existed elsewhere in the file, a name-only F12 would jump into it. Line 7 is
# `  r = down(n - 1)`, and SynEdit's Home is a SMART home -- it lands on the
# first non-blank, which is the `r` itself, so no arrow key is needed. Measured:
# Home plus three rights landed on the `=` and F12 correctly answered "no name
# under the caret", which is a true answer to a question nobody meant to ask.
key ^g
wait 500
key ^a
type 7
key {ENTER}
wait 600
key {HOME}
wait 300
key {F12}
wait 900
shot 141-a-parameter-is-not-a-function
