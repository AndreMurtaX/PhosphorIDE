# Send the selection to the REPL -- roadmap item 23, under gtk2.
# Same case as steps-sendrepl.txt; the keys are spelled the X way.
#
# sendrepl.bas holds a five-line definition on lines 7 to 11. All four of the
# item's done-when clauses are here:
#
#   * five selected lines reach the prompt as FIVE LINES, and `twice` is then
#     callable from it;
#   * SENDING WITH NO REPL RUNNING STARTS ONE FIRST -- nothing is started before
#     this script's first Ctrl+Shift+Enter, and the queue waits for the prompt
#     rather than racing it;
#   * the middle three lines are sent while the prompt is MID-BLOCK, so they
#     follow the `     ...> ` continuation exactly as typing them would;
#   * and the transcript is indistinguishable from the same lines typed by hand,
#     which the last shot is for -- a line is sent only when a prompt is
#     showing, one per prompt.
raise
wait 800

# The caret at the top of the definition, then five lines selected with Shift.
key ctrl+g
wait 600
type 7
key Return
wait 600
key shift+Down
key shift+Down
key shift+Down
key shift+Down
key shift+Down
wait 500
shot 440-five-lines-selected
# THE SELECTION IS THE FEATURE'S INPUT, and the status bar is the only place
# that says so in words. Ctrl+G 7 puts the caret at 7:1 and five Shift+Downs
# leave it at 12:1 -- the exact shape ActSendToReplExecute's rule reads: a block
# that ENDS at column 1 does not include that line, so 7 to 12 is lines 7..11.
# Without this, a Ctrl+G that never reached its dialog would send whatever line
# the caret happened to be on and the rest of this case would fail one step later
# with no clue which half broke.
text 12: 1

# SEND. No REPL is running yet, so this starts one and waits for its prompt.
key ctrl+shift+Return
wait 6000
shot 441-the-definition-reached-the-prompt
# FIVE LINES REACHED THE PROMPT AS FIVE LINES, which is the whole of item 23.
# The first one lands on the `phosphor> ` that the REPL this send STARTED printed
# -- nothing was running before line 35 -- and the echo closes that prompt's line
# (AddReplText continues the open fragment), so the transcript reads exactly as
# if it had been typed.
text phosphor> function twice(n) local r
# AND THE LAST OF THE FIVE ARRIVED MID-BLOCK. `endfunction` is fixture line 11,
# and it is sitting behind a CONTINUATION prompt -- five spaces and `...> ` --
# which only happens if the queue waited for each prompt and sent one line per
# prompt. A send that dumped all five at once, or that stopped after the first,
# cannot produce this line.
text ...> endfunction

# AND IT IS CALLABLE. Ctrl+Shift+R puts the caret in the prompt's box.
key ctrl+shift+r
wait 800
type println twice(21)
key Return
wait 2500
shot 442-and-twice-is-callable
# AND `twice` IS CALLABLE, which is the other half of the done-when -- and this
# is the host EXECUTING what was sent, not the editor echoing it. `inside twice`
# is printed by fixture line 9, the MIDDLE of the block: it can only appear if
# every one of the five lines arrived, in order, behind its own prompt.
text inside twice

# One more, to show the transcript keeps reading like a session.
type println twice(4)
key Return
wait 2000
shot 443-the-transcript-reads-like-typing
outtab
