# different height on different runs -- 700, 725 and 750 all seen on the same

# The output panel is bottom-anchored; from the bottom, every row keeps its
# place. Two earlier attempts clicked into the variables list instead of the
# stack, and both read as a pane that did not work.

#   tab strip   184 up   (Call Stack at x 191, Variables at 289)

# THE SESSION IS RUNNING, asked of the status bar, which is SHOWING whatever any
# tab click did. `debug deep.bas` is what the run label reads while a session is
# live; when the session has ended it says something else.
text debug deep.bas

# THE HOST ANSWERED. Without a phosphor binary the Debug menu is greyed and none
# of the above happens, so this separates "the session ran" from "the editor
# drew a debug-looking window".

# while the rows behind it are not.
