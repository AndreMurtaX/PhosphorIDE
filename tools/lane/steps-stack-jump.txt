# Now that every frame carries a line, a CALLER can be jumped to -- which is what
# a call-stack pane is mostly for, and what the host owed until 2026-09-16.
# Double-click (main) and the caret must land on line 11, the outermost call.
fixture deep.bas

key ^g
wait 700
type 4
key {ENTER}
wait 500
key {F5}
wait 500
key +{F9}
wait 5000
uiatab Call Stack
wait 600
uiadbl DataItem:4
wait 900
shot 31-jumped-to-main

# THE ROW ASKED FOR BY NAME. This was `dblclick 100 667` under a tab click that
# had selected Find in Files, so it landed in the search pane: the caret never
# left line 4 and the case passed, because it asserted nothing.
#
# Line 11 is `total = down(3)`, the outermost call.
uiaeq 11: 1
uiarow DataItem:4 4|(main)|11|deep.bas
memo
