# The REPL pane under gtk2. The Linux driver had no text reader when this was written -- roadmap item 28 gave it one, and this case has not been rewritten to use it -- keys go in
# through XTest and frames come out through xwd, because this VM has neither
# xdotool nor ImageMagick -- so every assertion here is a screenshot rather than
# a transcript read back. What it CAN check that the Windows side cannot as
# directly is the done-when's last clause: the driver prints `phosphor children`
# after the steps, and after End it must say none.
raise
key ctrl+shift+r
wait 2500
shot 150-the-prompt-arrived

# 42, which is the whole of what a REPL is for.
type println 6*7
key Return
wait 1500
shot 151-six-times-seven
# THE PROMPT IS NOT A LINE, AND THE ECHO CLOSES ITS LINE. `phosphor> ` is
# written before every read with no newline (uphosphorrepl.pas:75, citing
# host/console/phosphor.lpr:3746), so it reaches the pane only through
# FlushPrompt's two idle drains -- and SendReplLine then appends the typed line
# to that open line (umainform.pas:2688-2694). One needle asserts both.
text phosphor> println 6*7
# 42, which is the whole of what a REPL is for: a number the host computed and
# handed back over the pipe, not a string this repository wrote down.
text 42

# AND THE PERSISTENCE THAT JUSTIFIES THE PANE: Run hands the host a FILE and
# every run starts from nothing; these two lines are one session.
type x = 1
key Return
wait 1000
type println x
key Return
wait 1500
shot 152-a-variable-survives-the-line

# A block waits for its terminator and says so with `     ...> `.
type for i = 1 to 3
key Return
wait 1000
type println i
key Return
wait 1000
shot 153-the-continuation-prompt
# THE CONTINUATION PROMPT IS FIVE SPACES AND `...> ` (uphosphorrepl.pas:76), and
# the echo lands on it exactly as it lands on `phosphor> `. Leading spaces are
# left off the needle on purpose -- the driver takes everything after `text `,
# and a count of spaces is not what this asserts.
text ...> println i
type next
key Return
wait 1500
shot 154-the-block-ran
